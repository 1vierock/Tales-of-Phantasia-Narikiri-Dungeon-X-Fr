## Installation

1. Procurez-vous votre propre exemplaire de la version anglaise de PaLe Abyss ouhttps://github.com/lifebottle/Narikiri-Dungeon-X pour PSP.
2. Téléchargez le dernier patch de traduction en anglais depuis la page [Releases](../../releases).
3. Appliquez le patch `.xdelta` à votre fichier ISO d'origine à l'aide d'un outil de patch XDelta.
4. Lancez le jeu modifié sur une PSP ou un émulateur PSP.

> ⚠️ The original game is not included with this project.
